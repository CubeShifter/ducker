# Project Title

A nifty pcb that works as a devboard and can do audio, can be battery powered, and also has a lil breakout board for a keyboard switch and a led.

## Description

I have this fidget that whenever you click it, it makes a loud quacking noise, lights up, and is really cool/annoying. I wanted to try to make my own, and this is my second attempt at doing that. When I started making this project, I came into it with these goals
- make it click
- make it make noise
- pretty low power
- can store audio files
- led
- pretty tiny working space
and I managed to do all of those. It uses a CH552(g i think) chip, has 16mb of flash, usb breakout, can contain a lipo and charge it, has a pam 8302 audio amp, can power an led and has a circuit to cut power supply to it. 
## Getting Started
First of all, you need to get it fabbed. I would reccomend ordering from JLCPCB, and you should probably panelize the pcbs because free pcb.  For actual parts I would reference the BOM, they are 805s and stuff so you can probably hand solder it but PCBA is also fine. All production files are in the repo already :3

As of now, there is no official firmware you should flash it with, but there will probably be some soon. This is also a devboard, so you can play around and do whatever you want with it.
